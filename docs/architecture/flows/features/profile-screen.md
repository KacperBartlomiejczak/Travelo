# Profile screen and travel stats

Entry: tab „Profil” and the gear to Settings. Stats are counted on the phone from the trip list, so they work offline.

`ProfileScreen`: header „Profil” + gear (`IconButton` → `/settings`), the photo + nick row, `TravelStatsCard`, the offline banner above the pill; refetches the own profile on offline → online (D18). `ProfilePhoto` (inside it): 96dp circle; tapping it with a photo pushes `/avatar`, without one opens the gallery (see [profile-settings.md](profile-settings.md)); no `avatarId` → person placeholder; with one and a url → `profile-photo-skeleton` (`SkeletonBlock`) until the `Image` has loaded, then the skeleton fades over `duration.small` (D22, none with reduced motion); with one but no url (offline start) or a failed url → `profile-photo-initial`, the nick's first letter uppercased in `labelLG` on `background.sunken`, hidden from screen readers, not tappable (profile-settings D22); a failed url is retried once per offline → online change; a photo already shown stays when a later url fails or a read has none (D21, D23). `TravelStatsCard`: `Card` „Twoje podróże”, 2-column grid (one column above `fontScale` 1.3), lucide icons, numbers by `Intl.NumberFormat`, one screen-reader element per stat; loading → five `SkeletonBlock`s, failed with no copy → „–”. `SettingsScreen` and the rest of the settings: see [profile-settings.md](profile-settings.md).

**profile-upgrade:** the nick row adds `ProBadge` (`IS_PRO = true` placeholder in `ProBadge.tsx`, optional `pro` prop for tests, D19; SVG gradient `brand.primary` → `accent.sun`, text `brand.onBrand`). `FriendCode` (shown once the profile is read, also from the offline copy) sits between the profile row and `TravelStatsCard` (unchanged, D6); its share button calls `Share.share({ message: profile.shareMessage })`, failures and cancel are silent. `PastTrips` under the stats gets `tripSections(trips, deviceToday(now)).past` from the same `useTripList` read: state `loading` / `error` (no data and an error, no retry) / `ready` (data wins over a later error). Card: `CoverImage` full, SVG ramp from transparent to `hero.scrim` (alpha via `stopOpacity`) reaching full at half height (D20), min height `card.tripImageHeight`, `radii.lg`, pill in `hero.control*`, place = `findAirport(destination)?.city` or the IATA code, friends = `travellerCount − 1` (`pastFriends` plural / `pastSolo`, no line without the count). Tap: `useSelectTrip().mutate(id)` unless it is the current trip, then `router.navigate('/')`.

Plan and decisions: `prompts/profile-screen/plan.md`, `prompts/profile-upgrade/plan.md`.
