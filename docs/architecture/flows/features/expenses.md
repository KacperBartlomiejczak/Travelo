# Expenses (works offline)

Entry: the "Expenses" tab in the pill. Screen and components: see `/expenses` in [frontend.md](../../frontend.md). Decisions D5–D25 are in `prompts/expenses/plan.md`.

- **Write:** `useSaveExpense` / `useDeleteExpense` (`src/hooks/useExpenses.ts`, `networkMode: 'always'`) → `createExpenseRepository` (`src/data/expense-repository.ts`) writes SQLite through `store.writeGuarded` (store queue + user epoch, so nothing lands after sign-out; a dropped write throws `ExpenseWriteDroppedError`). The row is `pending` and is its own outbox entry. Other currency than the trip's base → `CurrencyMismatchError`; a linked friend writing another's row → `NotYourExpenseError`. Deletes are soft (`deletedAt`).
- **Sync:** `createExpenseSync` (`src/data/expense-sync.ts`), driven by `BudgetSyncProvider` with the budget (start, reconnect, foreground, after a save, and when a trip's list opens via `useExpenses(tripId)`; a run is skipped, and nothing counted, when there is no signed-in session or no connection check; one retry timer at the earliest `nextAttemptAt`; `Promise.allSettled`; invalidates `['expenses']`). Push: each unsynced row → `rpc('upsert_expense')`; marked `synced` only if `updated_at` is still what was sent; status 0 stays `pending`, a refusal becomes `failed` with backoff 1 s × 2ⁿ up to 5 min. Pull: every trip in the local list copy, all rows including soft-deleted; a newer server row replaces only a `synced` local row. Server timestamps are rewritten to `…sssZ` so they compare as text with the device's.
- **Read:** the list is ordered by `spent_on desc, created_at desc` and filters soft-deleted rows (`expense-repository.ts`), while the pull above does not filter them. Edit rules come from `useExpenseWriter` and `useCanEditExpense`.
- **Screen states** (`ExpensesScreen`): loading skeleton (`expenses-loading`); no trip → the trips empty state ("Create trip"); trips load error → "Try again"; expenses load error → "Couldn't load expenses."; empty list → `empty.expenses.*` copy with an action; the offline banner; the FAB shows only when the list is non-empty; the trip bar opens the drawer. Saving shows "Expense saved" or, while unsynced, "Expense saved. Waiting to sync." (`ExpenseSheet`). Components: `ExpenseSheet`, `BudgetHero`, `SpendByPersonChart`, `ExpenseTimeline`, `ExpensesHeader`, `PersonCategoriesSheet`.
- **Numbers:** pure `computeExpenseBudget` and `groupExpensesByDay` (`src/lib/expense-budget.ts`, D7, D9, D10), rendered by the screen.
