# Home screen, trip list and side panel

Entry: `/` (tab „Podróż”) shows the current trip; the side panel lists all trips. Reads work offline from SQLite copies.

- **List:** `ensureSession` → `trips.select('id, name, cover_image_uri, destination, start_date, end_date, flight_segments(from_iata, to_iata), trip_members(id)').order('start_date').order('created_at')` (one query; the nested routes feed the profile stats, the member rows give `travellerCount` for the past-trip cards, profile-upgrade) → `photo:` covers signed (file + thumbnail, batches of ≤ 1000, `coverUrls`; presets need no Storage call) → `listItemFromRow` (Zod) → written to the list copy (also prunes the copies and the choice of trips no longer listed). Unreachable (postgrest `status: 0` or `AuthRetryableFetchError`, including the 20 s timeout) → the list copy; no copy → rejects; other errors reject.
- **Current:** the chosen trip (SQLite) → `trips.select('*, trip_members(*), flight_segments(*)').eq('id', …).maybeSingle()` → a `photo:` cover signed as for the list → `overviewFromRows` (Zod; segments outbound → return by position, members by name) → when the trip's `owner_id` is not the signed-in user, `rpc('trip_organizer_username', { trip_id })` sets `organizerUsername` (a refused / null / invalid answer keeps the nick already in the copy, else leaves it out; friend-invite D15) → written to its copy. Gone (no row) → the choice is forgotten. With no choice: the list is read and `defaultTripId(list, deviceToday(now))` picks the trip (soonest upcoming or ongoing, else the most recently ended), read the same way; no trips → `null`. Unreachable → offline: the chosen trip's copy, else the default trip from the list copy, an empty list copy → `null` (no trips), no copy → rejects (error state). A budget change still on the device is laid over the trip when it is newer than the server's (`budgetSyncStatus` = its status), otherwise `synced`.
- **Select:** stores the choice in SQLite (no network); `useSelectTrip` then resets the current-trip query, so the home screen shows its skeleton, then the chosen trip — never the previous trip.
